## 1. 目标

现状：段落、标题、表格单元格、列表项和引用段落里完整的行内 HTML（如 `<span style="color:red">红字</span>`、`<kbd>Ctrl</kbd>`、`<sup>2</sup>`、`<img src="a.png">`）显示成灰色等宽的“行内原文片段”。片段是不可进入的原子节点，看不到效果，里面的字只能去源码模式改。

做完后：

1. 白名单内的行内 HTML 在所见即所得模式下直接显示效果：颜色、按键框、上下标、下划线、高亮、粗斜体、删除线、链接、行内图片。
2. 光标走进某个元素时，只显示这个元素自己的开始和结束标签（灰色），效果保留，元素里的字可以直接编辑，中文输入法正常组词。
3. 白名单以外的标签、带危险属性的标签，仍是现在的灰色原文片段，绝不执行。
4. 未编辑的文档保存后与原文逐字节一致；编辑后只改动编辑过的字。
5. 在所见即所得里新输入的行内 HTML 立即显示效果，不用重新打开文档。

## 2. 范围

**做：** 行内 HTML 的识别、显示层、图片显示、光标与键盘行为、链接打开、可见文字统计；测试；文档。

**不做：**

- 块级 HTML（`<div>`、`<details>` 等）。现有块级渲染和原位编辑不变。
- HTML 注释。现有淡化显示不变。
- 无属性 `<br>` / `<br/>` / `<br />`。现有换行处理不变。
- 从网页粘贴时把 HTML 格式转换成 HTML 源码。现有粘贴行为不变。
- 菜单或快捷键插入 HTML 标签。
- 引用式链接、相对路径链接的打开。
- 升级或新增依赖。
- 版本号、标签、发版。

## 4. 设计

### 4.1 表示方式：标签就是源码文字

白名单内、符合 4.2 条件的行内 HTML **不再生成原子节点**。它的开始标签、内容、结束标签都作为普通文字留在文档里，和 `**加粗**` 的星号一样，由显示层隐藏标签、给内容加样式。

- 不得为这些元素新建 ProseMirror 节点或 mark 来承载格式。显示只用装饰（decoration）。
- 保存时文字原样写出。不要恢复全局转义，行首规则沿用 `guardLineStart`。
- 不符合 4.2 条件的 HTML 继续走现有的 `croquill_inline_raw` 原子节点。
- 同一段里可以同时有渲染的 HTML、原文片段、`**加粗**`、`==高亮==`、链接等，互不影响。只要段里所有行内 HTML 都能确定归类（渲染或原文片段），就不再因为“混合”而整段保护。

### 4.2 白名单

**成对标签（必须在同一个段落、标题或单元格内闭合，嵌套正确）：**

| 标签 | 显示 |
| --- | --- |
| `span` | 应用允许的样式（见下） |
| `kbd` | 按键框，样式与 Typora 相近，用主题变量，浅色深色都要清楚 |
| `sup`、`sub` | 上标、下标 |
| `u`、`ins` | 下划线 |
| `s`、`del` | 删除线 |
| `mark` | 与 `==高亮==` 相同的外观 |
| `b`、`strong` | 粗体 |
| `i`、`em` | 斜体 |
| `small` | 小一号字 |
| `a` | 与 Markdown 链接相同的外观；Ctrl+单击打开，见 4.6 |

**单标签：** `img`（见 4.5）。

**属性规则：**

- 任何以 `on` 开头的属性（不区分大小写），或属性名、属性值无法可靠解析：整个元素保持原文片段。
- `a` 的 `href` 协议不是 `http`、`https`、`mailto`（例如 `javascript:`、`data:`、`file:`、相对路径），或者没有 `href`：显示为链接外观，但 Ctrl+单击给出现有的“暂不支持”提示，不打开。
- `img` 的 `src` 只接受现有块级 HTML 已允许的来源（本地相对路径、`file:`、盘符路径经 `resolveImage`；`http`、`https`、`data:image/*`）。其他来源：保持原文片段。
- `style` 只允许出现在 `span` 上。只取这几项声明：`color`、`background-color`、`font-weight`、`font-style`、`text-decoration`、`text-decoration-line`。其他声明忽略，不影响该元素渲染。值里出现 `url(`、`expression(`、`\`、`<` 的声明一律忽略。样式要通过解析出的键值生成，**不得把原始 `style` 字符串直接写进 DOM**。
- `title`、`class`、`id`、`lang`、`dir` 允许出现，但不产生效果（`title` 可以作为悬停提示）。
- `img` 另外允许 `alt`、`width`、`height`。`width`、`height` 只接受正整数或带 `px`、`%` 的数，其余忽略。
- 其他属性：整个元素保持原文片段。

**保持原文片段（现状不变）：** 白名单外的标签（`script`、`iframe`、`button`、`input`、`font`、`center` 等）、带属性的 `<br>`、`<wbr>`、未闭合或跨块的标签、注释。

### 4.3 光标在元素外与元素内

规则与 Typora 实测一致，并沿用现有行内标记的显隐机制：

- 光标不在元素里：开始标签和结束标签都隐藏，内容按 4.2 显示效果。
- 光标在元素里，或者紧贴它的开始标签前、结束标签后（与现有 `**` 的“碰到就显示”规则相同）：这个元素的两个标签以现有标记的灰色样式显示，内容的效果保留。同一段里的其他元素不展开。
- 嵌套时，光标所在的每一层元素都展开；外层没被碰到的不展开。
- 元素里还可以有 `**加粗**`、链接等 Markdown 行内格式，按各自规则显隐。
- 方向键、Home / End、Backspace / Delete 跨过隐藏标签的行为，与现有隐藏的 Markdown 标记一致。不得让一次按键只删掉半个标签。
- `AGENTS.md` 的要求依然有效：光标所在位置不能放任何额外的 DOM 节点；输入法组词期间不得改动显隐状态导致组词中断。

### 4.4 输入与编辑

- 在所见即所得里打出一个完整的白名单元素（例如 `<kbd>A</kbd>`），打完结束标签的 `>` 后立即按 4.3 显示。
- 打到一半（只有开始标签）时，按普通文字显示，不报错、不进入源码保护。
- 把元素里的字全部删掉、只剩空标签（`<kbd></kbd>`）时，两个标签显示出来，光标停在两个标签之间，可以继续输入。
- 删除开始或结束标签中的任意字符，使元素不再成立时，剩下的字作为普通文字显示。
- 在所见即所得里输入的白名单外标签，在本次编辑中按普通文字显示；保存时原样写出，下次打开时按现有规则成为原文片段。

### 4.5 行内图片

- 光标没有碰到 `<img ...>` 这段源码时：把它显示成图片（用 widget 装饰并隐藏源码文字），`width`、`height` 生效，没写就按图片原始大小，但不超过正文宽度。
- 光标碰到（在标签内，或紧贴 `<` 之前、`>` 之后）时：显示源码文字（灰色），不显示图片。
- 本地图片通过现有的 `resolveImage` 异步读取。读取期间和读取失败时显示源码文字，失败时可以在旁边加一个“图片无法显示”的标识，但这个标识不能出现在光标所在位置。
- 图片可以通过选中整段源码删除，或光标在旁边时 Backspace / Delete 逐字删除源码。点击图片时把光标放到 `<img` 之后，显示源码，便于修改。

### 4.6 链接

- `<a href="...">文字</a>`：Ctrl+单击文字，经由现有 `onOpenLink` 和 Rust 命令打开；协议校验沿用 Rust 端的规则。
- 本次运行首次普通单击链接时的“按 Ctrl + 点击以打开此链接”提示，对 HTML 链接同样生效。

### 4.7 可见文字

- `visibleText()` 以及所有用它的地方（大纲、目录 `[TOC]`、字数统计、查找栏的可见文字高亮）不计入标签字符。`<kbd>Ctrl</kbd>` 计为 `Ctrl`；`<img>` 不计入文字。
- 查找仍然查 Markdown 原文（现有规则），包括标签。

### 4.8 与施工单 04 的衔接

- 切换源码模式时，渲染的 HTML 元素里的文字和标签之间的位置，按普通文字精确到字映射。
- 施工单 04 加的“公开样本全量扫描”测试必须继续通过，并覆盖新的 `examples/inline-html.md`。

## 5. 测试要求

用仓库现有的单元测试和浏览器应用测试写法，不修改现有测试的预期。**现有测试里凡是断言“白名单元素显示为原文片段”的，属于本单有意改变的行为**：在 PR 说明里逐条列出这些测试和改动前后的断言，改成新预期；不得删除测试来让它通过。

至少覆盖：

1. **识别：** 4.2 每个白名单标签各一例渲染；`on*` 属性、`javascript:` 链接、不允许的 `img` 来源、白名单外标签、未闭合、跨块、带属性 `<br>`、`<wbr>`、注释各一例保持原文片段；嵌套 `<b><i>x</i></b>`、`<span>` 里有 `**粗体**`、`**<u>x</u>**`。
2. **样式过滤：** 允许的六项声明生效；`position`、`font-size`、`url(...)`、`expression(...)` 等被忽略；DOM 上的 `style` 属性只含允许项。
3. **显隐：** 光标在元素外、元素内、紧贴开始标签前、紧贴结束标签后，以及嵌套时，标签的显示与隐藏符合 4.3。
4. **编辑：** 在 `<span style="color:red">` 内输入中文、删除字、删空元素再输入；模拟组词期间显隐不变、不派发会打断组词的事务。用仓库现有的模拟组词写法。
5. **输入即渲染：** 在所见即所得里逐字输入 `<kbd>A</kbd>`，打完 `>` 后渲染；只打开始标签时不进入源码保护。
6. **字节保真：** `examples/inline-html.md` 打开不编辑，`getMarkdown()` 与原文逐字节一致；LF、CRLF、BOM 各一份。编辑元素内一个字后保存，与原文只差这个字。表格单元格里的元素同样成立。
7. **图片：** 本地相对路径、`https`、读取失败三种；光标碰到时显示源码、离开时显示图片；`width`、`height` 生效；光标位置没有额外 DOM 节点。
8. **链接：** Ctrl+单击 `https` 调用 `onOpenLink`；`javascript:` 不调用并提示。
9. **可见文字：** 含渲染元素的标题在大纲里只显示文字；字数统计不计标签。
10. **切换定位：** 渲染元素内外的光标在两种模式间双向精确到字。

更新 `examples/inline-html.md`：上半部分改成描述新行为（哪些显示效果、哪些仍是原文片段），保留下半部分“仍应整块保护”的样本，补上 4.2 每个白名单标签和行内图片的示例（图片用仓库里已有的公开图片，不要新增私人素材）。
