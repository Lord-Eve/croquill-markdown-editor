## 4. 设计要求

### A. 段首退格

依据是官方 Typora 1.14.15 本机实测（`docs/typora-acceptance.md` 2026-11-24 一节）。光标在段落开头、没有选中文字、不在输入法组词中，按退格：

| 上方的块 | 要求 |
| --- | --- |
| 有内容的代码块 | 保持现状：段落并入代码块末尾，光标停在接缝处 |
| 空代码块 | **一次退格删掉空代码块**，段落原样留下，光标仍在段首 |
| 公式块 | 段落文字并入公式源码末尾，进入公式源码编辑，光标停在接缝处。之后的退格只删公式源码里的字，在公式源码开头按退格不删除任何东西。**不能清空文档或删掉公式** |
| 引用、列表 | 保持现状 |
| 表格 | 段落文字并入**最后一个单元格**末尾，光标停在接缝处。之后的退格逐字删单元格里的字；在单元格开头按退格，光标移到前一个单元格末尾，不删除内容。**不能选中或删掉整张表** |
| 分割线 | **一次退格删掉分割线**，段落原样留下 |
| 块级 HTML | 段落文字并入 HTML 源码末尾，打开原位源码框，光标停在接缝处，之后的退格只删源码里的字。**不能删掉整块** |
| 原文保护块（灰色等宽原文）、`[TOC]` 目录、其他不能直接编辑文字的块 | 退格不删除、不改写这一块；可以什么都不做，也可以只把光标移到该块前后，PR 里写清选了哪种 |

共同要求：

1. 上面每种“并入”都是**一步撤销**：按一次 Ctrl+Z 恢复成并入前的两块，光标回到段首。
2. 段落为空（只有光标）时，同样按上表处理，只是并入的是空内容。
3. 光标在段落开头、段落上方是标题或普通段落时，行为不变（施工单 08 的标题规则、`joinIndentedParagraph` 都要保留）。
4. 上方的块嵌在引用、列表、提示块里时，规则相同；嵌套层级不同的情况按 ProseMirror 现有行为，但同样**不能删掉带内容的整块**。
5. 段末按 Delete，下方是表格、公式、块级 HTML、原文保护块时，**同样不能删掉下方整块**。具体行为（例如把下方第一段文字并上来，或什么都不做）由你决定，PR 里写清楚。
6. 保存：施工单 10 的“只改动过的地方”照常生效，并入后只有被并入的块和被删掉的段落有变化，其余字节不变。
7. 输入法组词中按退格不触发上述任何处理（底线第 3 条）。

### B. Ctrl+单击本地链接

只处理所见即所得模式下行内链接、尖括号链接和行内 HTML `<a>` 的地址。外部链接（`http://`、`https://`、`mailto:`）保持现状。

1. **地址解析**：相对路径按当前文档所在目录解析；也接受绝对路径和 `file:///`。解码 `%20` 等百分号编码。地址可以带 `#片段`。路径解析和存在性检查放在 Rust 端，前端不拼接 Windows 路径。
2. **Markdown 文件**（`.md`、`.markdown`、`.mdown`、`.mkd`，不区分大小写）：在当前窗口打开，走现有打开流程，当前文档未保存时照常弹出“保存 / 不保存 / 取消”。地址省略扩展名时（Typora 文档允许 `[说明](Readme1)`），原路径不存在就依次试 `.md`、`.markdown`。带 `#片段` 时，打开后跳到对应标题。
3. **其他存在的文件或文件夹**：在资源管理器中选中显示（`explorer.exe /select,`），**不直接运行或用关联程序打开**。Typora 会用关联程序打开，这里有意不同：文档里的链接可能来自别人，直接运行本地程序有风险。
4. **文件不存在**：提示“找不到文件：<文件名>”，不新建，不改动文档。
5. **未保存的新文档**里点相对路径链接：提示先保存文档。绝对路径照常处理。
6. **只有 `#片段` 的链接**：在当前文档跳到对应标题，光标放在标题开头，标题滚入可见范围（Typora 实测如此）。找不到时提示“找不到标题：<片段>”。
7. **标题匹配规则**：与导出 HTML 共用一套规则，抽成一个共用函数，导出改为调用它，导出结果不能变。依次匹配：标题自定义 ID（`{#id}`）、标题文字、Typora 文档的写法（转小写、空格换成 `-`、去掉标点）；重名标题按导出的后缀规则区分。片段先做百分号解码。
8. 安全：Rust 端拒绝空路径、含控制字符的路径和过长路径；不经过 shell 执行文档里给出的路径。

### C. Ctrl 悬停手形光标

所见即所得模式下，按住 Ctrl 时指向第 B 节能处理的链接，或外部链接，鼠标显示手形光标。指针不动、按下或松开 Ctrl 时也要立刻切换。窗口失去焦点时恢复普通光标。输入法组词中不切换。

### D. 依赖声明

在 `package.json` 的 `dependencies` 里写上 `"katex": "0.19.1"` 和 `"@codemirror/language-data": "6.5.2"`（当前 `node_modules` 顶层实际安装的版本，写单时用 `npm ls` 确认过）。`package-lock.json` 只允许出现这两项声明带来的变化，**不能**有其他包的版本变化；PR 里贴出 `package-lock.json` 的 diff 摘要。
