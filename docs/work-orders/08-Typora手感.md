## 1. 目标

让四处手感和官方 Typora 一致：

| 项 | 现在 | 做完以后 |
| --- | --- | --- |
| A. 专注模式 | 没有 | F8 开关；只有光标所在的那一块是正常颜色，其余变浅 |
| B. 打字机模式 | 没有 | F9 开关；用键盘移动光标或打字时，光标所在行停在窗口中间附近 |
| C. 标题按键 | 行首 Delete 降一级；已有标题行首输入 `# ` 级别相加；一至六级都在左侧显示灰色 `#` | 行首 Delete 删掉后面一个字；`# ` 当文字留在标题里，级别不变；左侧级别提示只在四至六级出现 |

## 4. 设计

### A. 专注模式（F8）

- “视图”菜单增加“专注模式”，右侧显示 `F8`，开启时菜单项前显示勾。F8 和菜单都能开关。
- 开关状态记在 `localStorage`，下次启动保持。
- 开启后，所见即所得正文里只有“当前块”保持正常颜色，其余文字、列表符号、表格线、代码块文字都明显变浅。两套主题都要能看清当前块和变浅的部分。
- 当前块的范围（Typora 实测）：
  - 段落、标题：就是这一段、这一个标题；
  - 列表：只有光标所在这一项自己的那一段，不包括它下面的子项；
  - 表格：光标所在的整行（两格都亮），表头行也算一行；
  - 代码块、公式块、原文保护块：整块；
  - 引用、提示块、脚注定义里的段落：光标所在的那一段（未在 Typora 实测，验收时对照）。
- 光标不在正文里（例如焦点在侧栏或查找框）时，保持最后一次的当前块。
- 只能用 ProseMirror 的节点装饰（class）或 CSS 实现，**不能在光标所在位置插入任何 DOM 节点**，组词期间不能改变光标所在块的 DOM 结构。

### B. 打字机模式（F9）

- “视图”菜单增加“打字机模式”，右侧显示 `F9`，开关和记忆方式同 A。
- 开启后，正文顶部和底部各留出约半个窗口高的空白，第一行和最后一行也能停在中间。
- 以下操作后，把光标所在行滚到正文窗口垂直中间附近（中线上下各 1/10 窗口高以内即可）：打字、回车、退格、删除、方向键、Home / End / PageUp / PageDown、Ctrl+Home / Ctrl+End、撤销重做、粘贴。
- 鼠标点击和拖选**不**滚动，避免内容在鼠标下跳走；之后一按键再居中。
- 拼音组词期间不滚动，上屏后再居中。
- 与现有逻辑不打架：大纲点击跳转、模式切换后的位置恢复、查找跳转期间不抢滚动；用户正在用滚轮或滚动条时不拉回。
- 关闭后去掉多出的空白，光标所在行在窗口里的位置不跳。

### C. 标题按键

1. **行首 Delete**：光标在有文字的标题最前面按 Delete，删掉标题的第一个字，级别不变，与段落里的 Delete 一样。删到标题没字时，再按 Delete 的行为与空段落相同。
2. **已有标题行首输入 `# `**：`#` 和空格都作为标题文字留下，级别不变。保存写成 `## # 二级标题`（Typora 的写法，不加反斜杠）。重新打开仍是二级标题，文字是“# 二级标题”。段落行首输入 `## ` 变标题的现有行为不变。
3. **左侧级别提示**：光标在四至六级标题里时，左侧仍显示灰色的 `####` / `#####` / `######`；一至三级不再显示。引用的 `>` 提示不变。
4. 组词期间以上按键全部不拦截。

### D. 单个换行

1. **显示**：段落里的单个换行（源码里一行接一行，中间没有空行）照原样分行显示，包括列表项、引用、提示块里的段落。`:::` 容器写法因此三行分开显示。字数统计、大纲、目录、查找结果不受影响。
2. **Shift+Enter**：在段落里（包括列表项、引用里的段落）按 Shift+Enter，插入一个软换行，显示为另起一行，保存为一个换行（文件是 CRLF 的照旧由保存时统一）。
   - 新行行首如果会变成别的结构（`#`、`-`、`1.`、`>` 等），由现有的 `guardLineStart` 加转义，不能让段落变成列表或标题。
   - 列表项和引用里的续行要带上正确的缩进或 `> ` 前缀，重新打开仍在同一项、同一个引用里。
   - 软换行停在段落最末尾且后面没有文字时，Markdown 会把它丢掉。这种情况保存时继续用现在的 `<br />` 写法，保证空行不丢。
3. **不变的部分**：标题、表格里的 Shift+Enter 仍写 `<br />`；文件里原有的 `<br>`、两空格硬换行、反斜杠硬换行显示和保存都不变。
4. 光标在软换行前后移动、在新行行首用拼音组词、撤销重做都要正常；模式切换定位（`mode-position.ts`）对软换行的现有行为不变。
5. 打开后不编辑，保存必须与原文逐字节一致，包括含软换行的 LF、CRLF、BOM 文档。
