# 编辑内核技术验证

记录日期：2026-10-27。本记录只覆盖独立编辑内核测试；真实桌面文件对话框、磁盘写入、关闭窗口和系统中文输入法由桌面验收另记。

## 已实现

- `src/editor.ts`：Milkdown / Crepe 7.23.0 富编辑与 CodeMirror 6 源码编辑。段落、标题、列表、任务列表、引用、链接、表格、代码、图片和 KaTeX 数学公式使用成熟内核。
- 原文独立存储；打开和未编辑切换不采用内核的规范化输出。真实文档变化才更新保存文本；同步 `getMarkdown()` 可在文件操作前取到最新事务。
- 保留初始富编辑文档与源码状态。撤销回初始内容时恢复原始文本，包括原来的 CRLF 和标记风格。
- 富编辑仅对当前标题块显示灰色标题标记装饰；它不是 Typora 的完整语法显隐实现。
- 图片通过显示代理解析，Markdown 仍保存原来的图片路径。额外扩展图片块 schema 保留真实 alt 与 title，修复 Crepe 默认把 alt 写成缩放比例 `1.00` 的行为。
- frontmatter、原始 HTML、脚注、双链、指令块等已知不支持结构使用源码保护；另以 CommonMark / GFM / math AST 对比检查初次解析和序列化是否保留结构。
- 大纲忽略文首 YAML / TOML 元数据，保留正文标题的原始行号。

## 验证结果

执行方式：Vite 独立开发页 `tests/harness.html`，通过浏览器界面运行测试按钮。测试页没有进入正式产品入口，也没有向正式产品暴露调试 API。

| 项目 | 结果 |
| --- | --- |
| 混合 CommonMark / GFM 文档 20 次源码与富编辑往返 | 原始文本完全不变，修改事件为 0；含 CRLF、加粗/斜体/删除线、链接、嵌套列表、任务列表、表格、带语言代码块和相对路径图片 |
| 图片信息保留 | 相对路径交给图片代理；修改标题后 alt / title 保留，撤销恢复原文 |
| 富编辑撤销重做 | 修改标题、撤销恢复原始 CRLF 文本、重做恢复新标题通过 |
| 源码程序化中文编辑 | 中文、标点、同步、撤销、重做、模式往返保留修改通过；此项不是系统 IME 选词测试 |
| 不支持语法 | frontmatter、HTML、脚注、双链和指令块进入源码保护，尝试切换不改原文、不产生修改事件 |
| 插入命令 | 标题、任务列表、表格、链接和图片面板通过 |
| 数学公式 | 行内 KaTeX 与块级 `.katex-display` 实际 DOM 渲染通过；修改正文标题后公式语法保留，未编辑模式切换保持原文 |
| 元数据大纲 | `title: 元数据` 不再成为 setext 伪标题，正文标题行号正确 |
| 长中文文档 | 56,297 字符、1,400 段；浏览器中加载及标题变更约 445 ms，末段仍保留。此值不代表持续输入延迟或真实桌面滚动帧率 |

代码块和块公式使用 Crepe 的 IntersectionObserver 延迟挂载。公式测试先滚入可见区域，再等待真实 DOM 挂载，避免把占位代码块当成渲染结果。

`npm test -- tests/fidelity.test.ts`：4 项通过，包含保护检测、代码/自动链接排除、AST 结构比较和大纲行号。新增 math 和 frontmatter 大纲逻辑后已执行该定向测试。最终 `npm run build`：TypeScript 与 Vite 构建通过。

## 保真和交互边界

- 编辑后的内核输出可能把列表符号统一为 `*`、重新布局列表空行和表格分隔行、转义普通文本中的标记。未编辑时使用原文；编辑后的字节一致性没有作出承诺。
- 源码保护针对整个文档。暂不提供 frontmatter / HTML 的富编辑预览和局部原始块编辑。
- 两种模式的撤销历史在该模式文档没有变化时保留；另一模式发生编辑后，重新建立目标模式文档与历史，不提供跨模式统一撤销栈。
- 单块语法显隐、光标位置映射、链接及图片内联编辑、表格工具的完整交互仍以 Crepe 为基础，不能称为完整 Typora 复刻。
- 本记录没有验证真实中文 IME 候选词、组合输入撤销、剪贴板来自 Word 的富文本或长文滚动帧率。
