# 路线图与已知问题

完成一项就勾选，并在 `CHANGELOG.md` 里记录。新发现的问题加到对应阶段。

## 第 1 阶段：日常能放心替代 Typora

- [ ] **放宽源码保护。** 现在文档里只要出现 frontmatter、HTML、脚注、`==高亮==`、`[TOC]` 之一，整篇就被锁进源码模式。改为能渲染的就渲染，不能渲染的只把那一块显示为原文。
- [ ] **图片存为文件。** 粘贴或选择图片时，现在会把图片转成 base64 塞进 .md 文件。改为像 Typora 一样复制到 `assets` 文件夹，并写入相对路径。同时开启拖放图片。
- [ ] **保留原有 Markdown 写法。** 编辑后保存，`-` 列表会变成 `*`，表格分隔线会被重排。尽量保留原文写法，至少默认输出 `-`。
- [ ] 所见即所得模式下的查找替换（Ctrl+F / Ctrl+H）
- [ ] 最近打开的文件；启动时恢复上次的文档
- [ ] 安装包、`.md` 文件关联（双击 .md 用 TyporaX 打开）

## 第 2 阶段：Typora 的手感

- [ ] **行内语法随光标显隐**：光标进入加粗等格式时显示 `**` 等标记，离开后隐藏，且标记可以直接编辑
- [ ] 标题的 `#` 可编辑：删掉 `#` 变回正文，加 `#` 改级别
- [ ] 链接点击后原位展开编辑
- [ ] 大纲跟随滚动高亮当前章节，可以折叠
- [ ] 左侧“文件”标签：文件夹树
- [ ] 焦点模式（F8）、打字机模式（F9）
- [ ] 切换源码模式时保留光标和滚动位置

## 第 3 阶段：锦上添花

- [ ] 导出 PDF / HTML
- [ ] 多标签页或多窗口
- [ ] 自动保存
- [ ] 自定义主题（加载 CSS）
