# 路线图与已知问题

完成一项就勾选，并在 `CHANGELOG.md` 里记录。新发现的问题加到对应阶段。

## 第 1 阶段：日常能放心替代 Typora

- [x] **长文输入延迟整理。** 富编辑输入立即标记修改，停手约 300ms 后序列化；保存 / 切换 / 关闭前强制同步，滚动期间延后尚未开始的整理。私人样本前后性能数据与边界见 `docs/performance.md`。
- [ ] **进一步缩短长文整理时间。** 当前样本停手后单次全文整理仍约 0.64 秒，保存也需等待；纯静止文档滚轮在 Edge 基准中未复现明显卡顿，真实 WebView2 如仍卡顿需另行采集该窗口的渲染轨迹。
- [x] **放宽源码保护（第一批）。** 用 remark 解析结果识别 HTML；HTML、脚注、高亮、目录、双链、容器、属性及提示块在所属块原样保留，其他段落可继续富编辑；文首 YAML 原文与正文分开处理。TOML、未闭合 YAML 及无法通过结构等价检查的文档继续保护。
- [x] **表格 `<br>` 与正文段内换行。** 无属性 `<br>`、`<br/>`、`<br />`（不区分大小写）支持所见即所得换行，保存保留原写法；表格内 Shift+Enter 新增换行写为 `<br />`，删除换行同步删除标签。带属性的 `<br>` 及其他完整行内 HTML 由下列行内原文片段处理；手动验收样本见 `examples/br-in-table.md`。已构建，表格显示与局部保存通过本机验收；官方输出对照及未完成的桌面项目见 `docs/typora-acceptance.md`。
- [x] **第二批：行内 HTML 原样保留为片段。** 段落、标题、表格单元格、列表项和引用段落里的完整行内 HTML 显示为灰色等宽原文片段，内部不可编辑，旁边文字可编辑，支持整个片段删除和编辑器内复制粘贴；保存保留原始字节，表格采用局部保存。块级 HTML、未闭合或跨段落 / 单元格标签及混合其他保护语法的块继续保护。**HTML 渲染效果尚未实现**，也不提供点击片段编辑；手动验收样本见 `examples/inline-html.md`。
- [ ] **放行语法的 Typora 式渲染（第二批）。** 分别对照并实现 `<span>` / `<kbd>`、`<details>` / 居中 `<div>`、HTML 注释隐藏、`==高亮==`、`[TOC]`、脚注、双链、`:::` 容器、`{#id}` / 类属性、`> [!NOTE]` 提示块；支持局部编辑，减少切到源码模式的需要。第一批仅保留原文，不承诺这些语法已有对应排版。
- [x] **换行保真补漏（PR #1 审查）。** 段落、单元格和表头末尾新增换行保存为 `<br />`，原有标签保持原写法；引用、列表及多层嵌套中的 `<br>` 表格采用局部保存，保留原表格式和容器前缀。
- [x] **空列表项正常编辑。** 单独的 `1.`、`7)` 和无序空项不再让列表整块保护；未编辑保存保持原文，编辑别处保留空项的编号、标记与空白，填入内容后按普通列表编辑。
- [x] **图片存为文件。** 粘贴、拖入和菜单选择本地图片统一保存到“文档名.assets”，Markdown 使用相对路径；重名自动加后缀，未保存文档先确定保存位置。
- [ ] **另存为后的图片路径。** 另存为到其他文件夹时，处理原有相对图片路径和附件目录的迁移。
- [x] **默认输出 `-` 无序列表。** 已通过 Milkdown 序列化配置实现；嵌套列表、任务列表一并覆盖，未编辑原文保持不变。
- [ ] **保留更多原有 Markdown 写法。** 含 `<br>` 或行内原文片段的普通表格已保留原分隔线和空白，其他表格及语法仍可能被规范化；继续减少无关格式变动，不承诺编辑后的字节完全不变。
- [ ] 所见即所得模式下的查找替换（Ctrl+F / Ctrl+H）
- [ ] **拖入 `.md` 文件直接打开。** 目前外部非图片文件统一忽略，后续接入现有打开与未保存确认流程。
- [ ] 最近打开的文件；启动时恢复上次的文档
- [ ] 安装包、`.md` 文件关联（双击 .md 用 Croquill 打开）
