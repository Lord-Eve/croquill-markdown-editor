## 第 1 阶段：日常能放心替代 Typora

- [x] **保存后继续编辑与撤销。** `run()` 解除 inert 后恢复编辑区焦点及编辑器模型选区；打开、新建、模式切换和插图的聚焦统一延后，有弹窗或其他控件接手时不抢焦点。富文本 / 源码跨保存点撤销、重做，回到保存内容时取消脏标记；另存为改写图片路径重载、重新打开文档允许清空历史。诊断和验收见 `docs/save-focus-acceptance.md`；CI 键盘脚本按已验证的 `gui-acceptance-v2.ps1` 原样替换。
- [x] **长文输入延迟整理。** 富编辑输入立即标记修改，停手约 300ms 后序列化；保存 / 切换 / 关闭前强制同步，滚动期间延后尚未开始的整理。私人样本前后性能数据与边界见 `docs/performance.md`。
- [ ] **进一步缩短长文整理时间。** 当前样本停手后单次全文整理仍约 0.64 秒，保存也需等待；纯静止文档滚轮在 Edge 基准中未复现明显卡顿，真实 WebView2 如仍卡顿需另行采集该窗口的渲染轨迹。
- [x] **放宽源码保护（第一批）。** 用 remark 解析结果识别 HTML；HTML、脚注、高亮、目录、双链、容器、属性及提示块在所属块原样保留，其他段落可继续富编辑；文首 YAML 原文与正文分开处理。TOML、未闭合 YAML 及无法通过结构等价检查的文档继续保护。
- [x] **表格 `<br>` 与正文段内换行。** 无属性 `<br>`、`<br/>`、`<br />`（不区分大小写）支持所见即所得换行，保存保留原写法；表格内 Shift+Enter 新增换行写为 `<br />`，删除换行同步删除标签。带属性的 `<br>` 及其他完整行内 HTML 由下列行内原文片段处理；手动验收样本见 `examples/br-in-table.md`。已构建，表格显示与局部保存通过本机验收；官方输出对照及未完成的桌面项目见 `docs/typora-acceptance.md`。
- [x] **第二批：行内 HTML 原样保留为片段。** 段落、标题、表格单元格、列表项和引用段落里的完整行内 HTML 显示为灰色等宽原文片段，内部不可编辑，旁边文字可编辑，支持整个片段删除和编辑器内复制粘贴；保存保留原始字节，表格采用局部保存。未闭合或跨段落 / 单元格标签及混合其他保护语法的块继续保护；**行内 HTML 片段本身的渲染与点击编辑尚未实现**（纯 HTML 块已支持渲染与原位编辑，见下方），手动验收样本见 `examples/inline-html.md`。
- [x] **第二批渲染：高亮。** 按官方文档将 `==高亮==` 显示为可编辑的黄色底色，保存写回 `==`；未改范围保留原写法，表格采用局部保存。
- [x] **第二批渲染：GitHub 提示块。** 支持 `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION` 的图标、英文标题和五色左边框，内容可编辑，保存保留原语法；同块还有其他保护类别时仍整块保护。
- [x] **第二批渲染：HTML 注释淡化。** 行内、独占和多行注释显示淡化原文，保存不改写；当前注释内部不直接编辑，可在源码模式修改。手动样本见 `examples/highlight-alert.md`；2026-11-10 桌面验收通过，见 `docs/desktop-acceptance-0.4.0.md`。
- [x] **第二批渲染：目录与脚注。** `[TOC]` 从全部标题实时生成只读目录，点击跳转；脚注上标支持悬停预览与跳到定义，完整多段定义可编辑、保存保持续段缩进，孤立引用原样保留。支持 LF / CRLF 与模式往返；同块有其他保护语法时仍整体保留。验收样本见 `examples/toc-footnotes.md`；2026-11-10 桌面验收通过，见 `docs/desktop-acceptance-0.4.0.md`。
- [ ] **放行语法的 Typora 式渲染（第二批剩余）。** `<details>` / 居中 `<div>` 等纯块级 HTML 已支持安全渲染与原位编辑（手动样本见 `examples/html-block.md`）；仍待实现行内 `<span>` / `<kbd>`、双链、`:::` 容器、`{#id}` / 类属性的支持。
- [ ] **块级 HTML 渲染后续增强：** 块内夹着的 Markdown 排版；`<video>`、`<audio>`、`<iframe>` 等媒体与嵌入内容按安全方案再评估是否支持。
- [x] **换行保真补漏（PR #1 审查）。** 段落、单元格和表头末尾新增换行保存为 `<br />`，原有标签保持原写法；引用、列表及多层嵌套中的 `<br>` 表格采用局部保存，保留原表格式和容器前缀。
- [x] **空列表项正常编辑。** 单独的 `1.`、`7)` 和无序空项不再让列表整块保护；未编辑保存保持原文，编辑别处保留空项的编号、标记与空白，填入内容后按普通列表编辑。
- [x] **图片存为文件。** 粘贴、拖入和菜单选择本地图片统一保存到“文档名.assets”，Markdown 使用相对路径；重名自动加后缀，未保存文档先确定保存位置。
- [x] **另存为后的图片路径。** 保留原图与附件目录，按新文档位置改写有关图片路径；同盘优先相对路径，跨盘用 `file:///`，不影响的路径原写法不变。先检查全部有关图片，再走现有安全保存，失败保留当前文档；新文档继续依赖原附件目录，没有复制一套附件。真实 Windows 上由 CI 的 `saveas-rebase` 验收通过。
- [x] **默认输出 `-` 无序列表。** 已通过 Milkdown 序列化配置实现；嵌套列表、任务列表一并覆盖，未编辑原文保持不变。
- [ ] **保留更多原有 Markdown 写法。** 含 `<br>`、行内原文片段或高亮的普通表格已保留原分隔线和空白，其他表格及语法仍可能被规范化；继续减少无关格式变动，不承诺编辑后的字节完全不变。
- [x] **所见即所得与源码模式共用查找替换。** Ctrl+F / Ctrl+H、高亮匹配、位置 / 总数、前后循环、区分大小写和全字匹配；查找 Markdown 原文，包含原文块和行内片段，当前匹配显示源码上下文。替换只改命中范围，保留其他字节，单次及全部替换均一步撤销；输入法组词期间暂停搜索。验收样本见 `examples/search-replace.md`；原有两种模式各自的撤销历史规则不变。
- [x] **拖入 `.md` 文件直接打开。** 保留 HTML5 拖放，通过 WebView2 的 `File` 原生路径接口打开真实磁盘文档，沿用保存 / 不保存 / 取消与读取错误保护；图片照旧插入，不影响正文拖动。Windows 原生路径桥做了交叉类型检查，真实资源管理器拖入留待 Windows 验收。
- [x] **最近打开与启动恢复。** 文件菜单持久保存最近 10 个文档；已不存在时提示、移除，当前丢失文件保留为未保存内容。启动优先命令行目标，否则恢复上次文档；新建清除恢复目标，最近列表保留。不自动恢复未保存草稿。
- [x] **全局快捷键与保存反馈。** Ctrl+S / O / N / Shift+S / F / H / / 在窗口层统一处理，兼容不同焦点、非拉丁键盘布局，避免失焦后的旧组词状态误拦；保存请求可排队，成功后状态栏显示时间。模拟组词与焦点回归不替代真实 Windows IME 验收。
- [x] **Windows 自动验收（GitHub Actions）。** 推送 main 自动在真 Windows runner 上做类型检查、前端与 Rust 测试、正式构建，再以键盘脚本实测打开/无编辑保存的字节保真、源码编辑保存与撤销恢复、另存为图片路径改写、重启恢复与新建后保持空白，证据留运行附件；拖入、真实输入法、Typora 对照仍需真人桌面验收。见 `acceptance/README.md`。
- [ ] 安装包、`.md` 文件关联（双击 .md 用 Croquill 打开）

## 第 2 阶段：Typora 的手感

- [x] **行内语法随光标显隐**：光标进入加粗、斜体、删除线、行内代码、高亮时显示 `**` 等标记，离开后隐藏；光标能走进标记，标记可以直接编辑。2026-11-13 项目所有者确定要和 Typora 完全一致；采用“源码常驻、标记隐藏”的做法（`docs/inline-source-spike.md`），三段实现（显隐与标记编辑、快捷键与输入、查找替换与性能）完成，真实拼音输入法在真实窗口实测通过，实测与遗留见 `docs/inline-source-acceptance.md`
- [x] **标题级别按 Typora 实测行为调整。** 官方 Typora 不显示、也不能直接编辑已有标题的 `#`，原定“`#` 可编辑”改为对齐实测：标题行首 Backspace 一步变正文；`Ctrl+0` 变正文，`Ctrl+=` / `Ctrl+-` 升降一级，`Ctrl+1`～`6` 重复按变回正文；段落菜单补齐四至六级、段落、升降级。源码模式改级别只替换行首 `#`，不再叠加出 `# ## 标题`。对照见 `docs/typora-acceptance.md`。
- [ ] 标题细节待对照后决定：行首 Delete 目前会降一级（内核默认，未对照 Typora）；已有标题行首输入 `# ` 加空格会把级别相加（未对照）；左侧灰色 `#` 提示 Typora 只在四至六级显示图标；真实拼音输入法下的标题按键未测
- [ ] 链接点击后原位展开编辑（可复用行内源码的显隐机制；目前输入链接写法会即时变成链接，已有链接仍用浮层编辑）
- [ ] 行内源码的后续：复制到 Word 等富文本程序时带着标记字符；输入的行内 HTML、裸网址要到重新打开后才显示为片段 / 链接；组词时紧贴标记的拼音显示为灰色
- [ ] 大纲跟随滚动高亮当前章节，可以折叠
- [x] 左侧“文件 / 大纲”标签：紧凑单行文件树，目录按需展开、点击切换文件、刷新、记住目录；侧栏可调宽与收起。正文以官方 Typora 为参照，文件导航密度按项目所有者提供的 Obsidian 截图取舍。
- [ ] 焦点模式（F8）、打字机模式（F9）
- [ ] 切换源码模式时保留光标和滚动位置
