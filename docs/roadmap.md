## 第 1 阶段：日常能放心替代 Typora

- [x] **保存后继续编辑与撤销。** `run()` 解除 inert 后恢复编辑区焦点及编辑器模型选区；打开、新建、模式切换和插图的聚焦统一延后，有弹窗或其他控件接手时不抢焦点。富文本 / 源码跨保存点撤销、重做，回到保存内容时取消脏标记；另存为改写图片路径重载、重新打开文档允许清空历史。诊断和验收见 `docs/save-focus-acceptance.md`；CI 键盘脚本按已验证的 `gui-acceptance-v2.ps1` 原样替换。
- [x] **长文输入延迟整理。** 富编辑输入立即标记修改，停手约 300ms 后序列化；保存 / 切换 / 关闭前强制同步，滚动期间延后尚未开始的整理。私人样本前后性能数据与边界见 `docs/performance.md`。
- [x] **进一步缩短长文整理时间**。约 106 / 424 KB 本机样本停手整理由 203 / 812 毫秒降至 3 / 4 毫秒。四组打开时间仍超过目标，大样本按键也未达标；约 398 KB 公开样本切回正文慢了 80 毫秒。完整对照见 [长文性能记录](performance.md)。
- [x] **全文整理不要改写没碰过的块**。长文和短文都按上次保存的源码保留未改块、空行和文件结尾。表格、列表、标题、代码、数学、引用和提示块里的文字改动保留原写法。局部索引缺失、跨块插删或邻近源码保护块、脚注定义时会整理全文，再尝试复用原文。重新解析与编辑内容不符时使用完整写出结果。公开样本见 `examples/save-untouched.md`。
- [x] **段首退格保护（施工单 12）**。表格、公式和块级 HTML 接收下方段落，光标留在接缝处。空代码块和分割线一次移除。原文保护块、目录和段末 Delete 的保护行为见 2026-11-24 的 Typora 对照记录。
- [ ] **长文打开和按键继续提速**。施工单 11（PR #15）已合并：约 400 KB 公开样本按键 74 → 17 毫秒，切回正文 1544 → 336 毫秒，打开 4074 → 2339 毫秒；四份样本打开都快于原来。真实窗口冷启动 400 KB 4.8 → 2.9 秒（Typora 2.7 秒），100 KB 2.1 秒（Typora 1.7 秒，差在程序自身启动）。剩余差距：公开样本打开离 600 / 2000 毫秒目标还差约 30 / 340 毫秒，主要是 micromark 解析和 ProseMirror 建 DOM。[长文性能记录](performance.md)
- [x] **焦点测试偶发超时。** 2026-11-24 实测：`tests/app-operation-focus.test.ts` 在 `main` 上本机连跑两次，一次全过、一次 3 个用例超时 30 秒，每次超时的用例不同。原因：ProseMirror 获得焦点 20 毫秒后会把它记的光标写回页面，测试在这之前按键挪光标，偶尔被拨回文首。已改为所见即所得模式下准备步骤直接设置光标，源码模式照旧按键；改后该文件连跑 5 次 41/41，全量 46 个文件 964 个测试全过。程序代码未改。
