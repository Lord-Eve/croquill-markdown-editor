## 手动验收步骤

1. 打开样本，确认上半部分的 HTML 各自只灰一小段，使用等宽字体，外观能与行内代码 `示例` 区分；图片、颜色、下划线及注释都显示原文，没有渲染效果。下半部分仍显示为整块原文。
2. 不编辑直接保存，确认内容与原文件逐字节一致；另存一份 CRLF 换行的样本重复检查。
3. 修改正文片段前后的文字，再修改表格里的“修改这里”，保存后检查片段原文、表格其他单元格、分隔线、空白及 `\|` 都没有变化。
4. 把光标放到片段前后，尝试进入片段内部，应无法修改内部；用退格和 Delete 分别删除整个片段，保存后检查对应 HTML 已消失，其余文字还在。撤销后应恢复。
5. 在编辑器里复制一个片段，再粘贴到正文和表格单元格中，确认仍是灰色原文片段，保存后原文没有转义或改写。多行片段或含未转义 `|` 的片段无法原样放进 Markdown 表格，粘贴或拖入时应提示并保留原文、光标；原文中的合法 `\|` 可正常粘贴。
6. 在片段紧挨着的位置使用中文输入法组词、选词和输入标点，确认不吞字、不跳光标；再在普通 `<br>` 表格里新增和删除换行，确认原有行为不变。
7. 在所见即所得和源码模式之间来回切换，确认内容不变。需要修改片段内部时，在源码模式修改。
