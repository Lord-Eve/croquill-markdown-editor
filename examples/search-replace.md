## 手动验收步骤（Windows）

1. 打开本文件，Ctrl+F 查找 `cat`；观察所有匹配的底色、当前位置 / 总数，连续点击上一个、下一个或 Enter / Shift+Enter，确认循环。依次切换区分大小写、全字匹配。
2. 在查找框用真实中文输入法组词输入“中文”；候选未提交时结果应保持不变，提交后才更新。Escape 关闭，Ctrl+H 打开替换；“编辑”菜单里的查找 / 替换也应可用。
3. 查找“查找”，替换成“已替换”；先单次替换，再全部替换。每次操作后直接 Ctrl+Z 应一步撤回该次替换，Ctrl+Y 重做；保存并用源码对比，仅命中的字节发生变化。分别另存 LF、CRLF 样本重复，未替换的空白、BOM、标签大小写、斜杠、`\|` 应不变。
4. 检查行内片段、注释、整块 HTML、双链原文块和嵌套表格中的命中；替换按原文执行，旁边的标签和表格结构不变。在单元格内尝试替换为未转义的 `|`，应提示且不修改；合法的 `\|` 可以替换。
5. Ctrl+/ 切到源码模式重复查找、替换和撤销；来回切换后原文应保持一致。搜索范围包含 Markdown 标记和元数据，隐藏内容可在查找栏的“当前匹配原文”中核对。
6. 目录条目应以正常宽度横排，H1–H4 逐级缩进，点击跳转；切换浅色 / 深色并调窄窗口再看。
7. 逐个检查“文件 / 编辑 / 段落 / 格式 / 视图 / 主题 / 帮助”下的命令，特别是鼠标点击“文件 → 保存”：应执行一次，不误点下方正文或按钮；键盘 Alt 打开菜单后用 Tab、Enter 也应正常。

只验收这个人工样本的副本；上述步骤是待执行清单，不代表已通过桌面实测。
