# 表格与正文换行验收

| 写法 | 换行内容 | 可编辑文字 |
| --- | --- | --- |
| 无斜杠 | 第一行<br>第二行 | 修改这里 |
| 紧贴斜杠 | 第一行<br/>第二行 | 保留原写法 |
| 空格加斜杠 | 第一行<br />第二行 | 保留空格 |
| 大写标签 | 第一行<BR>第二行 | 保留大小写 |
| 多次换行 | 第一行<br/>第二行<BR>第三行 | 可以删除换行 |

第一行<br>第二行

先不编辑直接保存，再修改表格里的“修改这里”并保存，确认其他单元格及标签写法不变。在单元格里按 Shift+Enter 新增换行后，切到源码模式应看到 `<br>`；删除该换行后，标签也应消失。来回切换所见即所得和源码模式，内容应保持不变。
