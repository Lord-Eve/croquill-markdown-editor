## Windows 手动验收步骤

请在云端 Windows 拉取 main 后运行 `build.ps1`，确认新版 exe 的修改时间。以下是待执行步骤，本文件不代表桌面已经验收通过。

1. 用新版 exe 打开本文件的工作副本。分别将焦点放在正文、源码、查找框、替换框、文件树、大纲、展开的菜单、原文块旁、行内片段旁，按 Ctrl+S：状态栏应显示“已保存”和时间，磁盘上的最新输入应齐全。
2. 在正文与源码中各输入一个字，马上 Ctrl+S。用真实中文输入法提交词语后马上保存，再从侧栏和查找框保存。组词尚未提交时不触发命令；提交后所有焦点位置都能正常保存。反复新建 / 打开、查找 / 替换、切换源码后再检查一次。
3. 在上述各处检查 Ctrl+O、Ctrl+N、Ctrl+Shift+S、Ctrl+F、Ctrl+H、Ctrl+/；新建、打开、另存为的取消应保留当前内容，快捷键不能穿透到编辑器插入字符或重复执行。若使用非英语键盘布局，也检查这些组合键。
4. 当前文档写入尚未保存的文字，然后从资源管理器拖入另一个 `.md`：分别选择保存、不保存、取消。取消后原文仍在；保存应包含刚输入的字。再试从窗口菜单栏、侧栏和源码区拖入同一个文档，打开后的当前路径必须是该真实文件。
5. 拖入一张图片到编辑区，应照旧插入并保存到当前文档的附件目录；再拖动正文选区，确认同段 / 跨段移动和撤销正常。多个 `.md` 或 `.md` 与图片混拖时应提示单独处理，不清空当前文档。
6. 连续打开 12 个临时文件，文件菜单应只列最近 10 个，重新打开旧项后移到最前。关闭再启动时恢复上次文档；带命令行路径启动时以指定文件为准。主动新建后重启应为空白，但最近列表仍在。
7. 在资源管理器删除一个最近文件，再点击该项：应提示并移除；当前正文保留。若被删的是当前文件，应显示未保存，关闭前仍提示处理内存内容。读取权限或编码错误不应误当成“文件不存在”。
8. 将本样本另存为到另一个目录，检查两张 Markdown 图片仍显示。原附件保留在原处，新 Markdown 仅改写有关图片路径；HTML `img src` 也更新，其余标题、表格、空白、注释、代码和普通链接都应保持原样。新文档继续引用原附件，没有另复制一套。
9. 如有另一个本地盘符，跨盘另存为应写成指回原图的 `file:///` URL。准备一份 LF、一份 CRLF 和带 BOM 的样本重复对比；同时检查附件同名但内容不同的目标目录，不能误用目标的另一张图。
10. 将原图片临时改名后再跨目录另存为，应提示图片不可用、取消此次写入，当前路径和正文仍在。恢复图片名后重试应成功；取消另存为或目标只读时也不能丢文字、移动或删除原图。
